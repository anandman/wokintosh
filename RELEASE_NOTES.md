# Wokintosh 2.0.5

Collector updates are easier to run and follow in **Settings → Machines**.

- **Update All.** Update every connected machine needing a collector update, including an outdated managed status observer on This Mac. Updates run one machine at a time and continue if a machine fails.
- **Visible progress.** The active machine shows an Updating label, spinner and current stage. An overall progress indicator names the machine being updated and its position in the queue; waiting machines are labeled too.
- **Clear results.** Each machine keeps its success, warning or error details after the update. Progress and results remain available when you close or switch Settings tabs. Existing collector backups, verification and rollback behavior are preserved.

Install this signed, notarized Mac update through Sparkle’s **Check for Updates**, then open **Settings → Machines → Update All** to bring any pending collectors up to date.

Collector code is unchanged from 2.0.4, so current collectors need no reinstall. The iPhone/iPad companion is also unchanged; its 2.0.4 build remains current.
