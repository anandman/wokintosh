# Wokintosh 1.1.0

Wokintosh can now update itself with Sparkle.

- Automatically checks for new releases and downloads updates in the background.
- Installs downloaded updates when you quit, or sooner with **Install and Relaunch**. A running dashboard is never forced to restart.
- Adds an **Updates** settings tab with check/download preferences and a manual update button.
- Offers **Check for Updates** in the full-screen rainbow menu and the macOS app menu, with a gentle reminder when an update is available.
- Verifies signed update feeds and downloads from Wokintosh's GitHub releases.

**One final manual install:** quit Wokintosh and install 1.1.0 to obtain the updater. Subsequent releases can be installed in the app. Your dashboard, machines and existing Calendar/Music grants are preserved. Remote collectors already on 1.0.1 need no update for this release.

The app and DMG are Developer ID signed, notarized and stapled. Automatic updates can be disabled in Settings → Updates.
