# Wokintosh 1.3.1

System widgets keep their large, readable presentation across machines.

- Matching-size System widgets use the same large-value grid, even when one machine has longer drive names. Headings wrap within their cells or truncate with full details available on hover; long labels no longer switch the entire widget to smaller inline readings.
- Value and gauge alignment stays consistent across equal-size widgets. Wide and portrait layouts, text scaling, disconnected-source status and overflow continue adapting to available space.

This patch preserves existing dashboards, source settings and unread notices. Install through **Check for Updates** or **Settings → Updates**, or download the signed, notarized and stapled DMG. The Sparkle feed and download use Wokintosh’s existing update key.
